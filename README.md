# Omar Ahmed — Portfolio
Responsive portfolio built with HTML, CSS, and JavaScript, based on Omar's resume.

## Deployment
GitHub Pages publishes the `main` branch from the repository root using the existing Pages configuration. The intended address is https://omarahmedowais.github.io/ . Remove the existing repository CNAME file and clear the custom domain in GitHub Settings → Pages before publishing. Push a commit to update the site.

## Development
Run `python3 -m http.server 8000` from this folder, then visit http://localhost:8000.

- `index.html`: projects, experience, skills, and contact links.
- `style.css`: responsive layout and original CSS project illustrations.
- `Omar-Ahmed-Resume.pdf`: downloadable resume.

Project illustrations are conceptual, not screenshots. Professional project descriptions explain contributions and do not imply ownership of the complete product. No dependencies, API keys, or build step are required.
